# Module 05 — Advanced Patterns

## Learning Objectives

1. Build generic dataclass repositories.
2. Use Protocol for structural subtyping (duck typing with type safety).
3. Write Pydantic discriminated unions and recursive models.
4. Combine dataclasses with Pydantic for layered architectures.
5. Implement mixins safely with dataclasses.
