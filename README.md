# SQLAlchemy Dojo

## Courses

### [Python 3.11 Classes, Dataclasses & Pydantic](./course/)

An interactive course on **when and where to write classes** using plain classes,
`@dataclass`, and Pydantic — with every lesson runnable as a Plotly Dash 2.17 app.

```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r course/requirements.txt
python course/06_capstone/app.py   # Full sales dashboard
```
